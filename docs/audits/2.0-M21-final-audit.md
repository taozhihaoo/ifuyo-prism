## 3. Current Architecture

## 4. Intelligence Core Domain Model

IntelBundle = {schema_version, project: ProjectIdentity, provenance, entities|facts|evidence|relations|findings: BTreeMap<id,_>}——去重、确定性遍历、bundle 携带项目身份（isolation）。

## 5. Entity Model

EntityId = `{kind}:{fnv1a16(stable_key|kind|canonical_key)}`；EntityKind 开放注册（9 个通用构造器 + `other()`；无 Godot/C# 种类——§51 合规）；Location 六态；Scope internal/external/unknown。

## 6. Fact Model

FactType 开放注册 + 7 个通用构造器；FactValue 结构化五态；subject 显式 Option（聚合事实 None）；origin/confidence+reason/freshness/evidence/observed_at/provenance 全链。

## 7. Evidence Model

内容寻址 id（同证据去重）；12+Other 种类；path/range/reference/note；`unavailable(reason)` 显式表达。

## 8. Relation Model

方向显式（id 覆盖 source|type|target）；Resolved|Unresolved 两态目标（§59）；12 种通用关系 + other；resolution 元数据。

## 9. Finding Model

复用 core Severity；Status 五态（open/resolved/suppressed/stale/unknown）；无行号稳定 id；remediation 可选。切片未产生 Finding（health 规则域归 M28，不重复造 findings）。

## 10. Provenance / Origin / Confidence

producer+producer_version(analyzer schema 版本)+observed_at；Origin 三级不可混用（测试）；Confidence 四级 + ConfidenceReason 必填来源；与 core Confidence 映射函数。

## 11. Freshness

四态显式字段；bundle 本身不假装 fresh。

## 12. AnalysisContext

project+scope(FullProject/Paths/Domain)+requested_capabilities+observed_at+CancellationToken；transient 不序列化不持久化（§42）。

## 13. Partial Result / Error Model

IntelOutcome{status, data?, warnings, errors}；complete/partial/failed/cancelled 四态构造器；取消保留部分数据（测试）；Error（Prism 失败）vs Diagnostic（项目问题）边界——解析诊断进 warnings 且状态保持 Complete（测试 + CLI 实测佐证）。

## 14. Entity Identity

同名不同文件 ≠ 同实体；改名不塌缩；跨项目不碰撞——三条 identity 测试（§43.1 全覆盖）。

## 15. Project Isolation

不同 stable_key ⇒ 不同 EntityId（测试）；bundle 级隔离；结构与 store 层隔离（prism-store 按 project_id）叠加。
