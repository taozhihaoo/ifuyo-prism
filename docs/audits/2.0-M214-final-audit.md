## 3-4. Artifact / Target（§五-§十一）

- Artifact 身份 = SHA-256（目录 = 排序 (path|size|hash) 串联整体哈希；
  内容变化 ⇒ 身份变化测试锁定；非 GUID/文件名/mtime §6）。
- Manifest（§7）：normalized sorted file list + sizes + hashes + Git
  linkage（注入不猜）+ symlink skip 诊断（§46）+ 有界上限（§44）。
- Target 身份 = fnv(kind|host|port|remote_root)（§9：hostname 相同 ≠ 同
  机器）；environment（dev/staging）只是标签非安全边界（§9 如实）。
- Credential：**引用边界**（os-keychain/env/ssh-agent/Unavailable——测试
  锁定序列化无明文密码字段 §10）；Local transport 无凭证需求。

## 5. Preflight + Policy（§十三/§十五/§61）

Checks：artifact manifest 非空 / hash 存在 / target root。Policy
data-driven（require_clean_git/require_artifact_hash/
block_critical_findings/block_unknown_preflight）；结论 reasons 可展开
（§80）；**UNKNOWN 默认确认不伪装 FAIL**——除非 policy 明确 BLOCK（§14
测试锁定双向）。M28/M29 findings 经 critical_findings 消费（§39）。

## 6-8. State Machine / Transfer / Apply / Verify / Rollback（§54/§18-§29）

- 状态机 14 态（§54 枚举化，非散落 if）；FailureStage 13 阶段（§26）。
- Transfer：逐文件 TransferItem（§57 Partial：73 成功 27 失败可回答）；
  Apply：Local releases/current rename（Windows 非严格原子如实 §22）；
  Verify：hash match + activation（§23 只做两步不宣称 app healthy）。
- Rollback（§29）：回退 last_successful release，生成**新** Record；
  History 重启保留（测试 `history_persists_across_reopen`）。
- policy FAIL ⇒ Preflight 阶段阻断零 transfer（§50 测试
  `policy_fail_blocks_execution`）。
