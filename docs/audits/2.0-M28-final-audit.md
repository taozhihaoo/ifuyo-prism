## 7. Finding Fingerprint / Lifecycle / Baseline / Suppression / Regression（§8-§12）

- 指纹 = finding id 集合；diff = 集合差/交（`diff_against_baseline`）。
- Regressed = 基线 `lifecycle.new` ∩ 当前存在（`mark_regressed`；基线文件
  自带上次 lifecycle）。
- Suppressed：不参与 New/Persistent/Resolved，不 FAIL Gate
  （`suppressed_does_not_fail_gate` 实测）。
- FACT（端到端三轮）：首轮 3 New + FAIL ⇒ 二轮 persistent=3/regressed=3 +
  PASS ⇒ 缩小文件后 resolved=1/regressed=2 + PASS。
