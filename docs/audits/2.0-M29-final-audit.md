## 25. M210 Preconditions（§120 §25）

M210（Debug Intelligence）在以下 M29 契约上继续：

1. **Finding/Rule 挂载不变**：日志域 findings 走同一 RuleRegistry
   （新 RuleCategory 扩展或 `other`），生命周期/Gate 免费复用。
2. **Secret 红action 先例**：日志/堆栈中疑似凭据必须复用
   `secrets::redact` 形态（前缀+长度），指纹不含内容——M210 的日志事实
   层直接沿用。
3. **Capability 语义**：`EnvironmentCapability`（Available/Unavailable/
   Partial/Unknown）是 M210 表达"日志不可得"的既有词表。
4. **不可信输入解析器**：手写扫描器（csproj/INI 模式）+ 有界读取 +
   malformed⇒诊断 模式可复制到日志格式解析。
